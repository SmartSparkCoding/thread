# THE THREAD OF DOOM

This project was created for 2 reasons

- to summarise the thread in #vibes - click the title on the webpage to go to the thread
- to prove I can use AI to make projects, therefore I can lead a vibes workshop

The site has changes like selection colour changes, clickable header that takes you to the thread, stopping the marquee when you hover, adding audio when you click on the sound effects button (press it to hear the slack notification sounds), then some co-assisted changes with AI like updating all the stats (ai did the maths and some other things) and improving the site with AI and a bunch of other stuff!!
